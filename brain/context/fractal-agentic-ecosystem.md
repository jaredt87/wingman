# fractal-agentic-ecosystem

- **Role:** local demo of a platform model with graph runtime, API, UI, starter
  packs, and governance layers.
- **Stack:** Python 3.11+, FastAPI-oriented API, JavaScript/CSS UI, YAML, and
  SQLite-related state store. `pyproject.toml` currently declares no runtime
  dependencies.
- **Start with:** `README.md`, `governance/`, `architecture/`, `specifications/`,
  `docs/agents.md`, and the relevant starter-pack docs.
- **Commands documented:** use `uv run`; the README documents graph build,
  scaffold, status, failure simulation, and API commands.
