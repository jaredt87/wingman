# Repository onboarding

1. Identify repository root, branch, and working-tree changes.
2. Read local agent/contributor/security instructions, README, CI workflows,
   and architecture docs relevant to the task.
3. Summarize purpose, stack, setup/check commands, change/review flow, and
   explicit gaps. Cite paths relative to that repo.
4. Treat absent documentation as unknown, not as evidence that a control or
   workflow does not exist.
5. Do not edit files or invoke external systems unless asked.
